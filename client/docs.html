Pokemon API Docs

Gen 1 Pokedex

Try it!

/getAllPokemon - GET/HEAD

Returns

Stringified array of JSON pokemon objects with simplified and reorded attributes

Format: [ {name: string, id: number, type:[string], weaknesses:[string], height: string, weight: string, next-evolution:[{num: string, name: string}] } ]

Example

Request: /getAllPokemon

Response: [ {name: string, id: number, type:[string], weaknesses:[string], height: string, weight: string, next-evolution:[{num: string, name: string}] }, ...]

/searchSinglePokemon - GET/HEAD

Query Params

Pokemon name

Returns

Stringified JSON pokemon object with simplified and reorded attributes

Format: {name: string, id: number, type:[string], weaknesses:[string], height: string, weight: string, next-evolution:[{num: string, name: string}] }

Examples

Request: /searchSinglePokemon
Response: 400 error - please enter a name

Request: /searchSinglePokemon?name=Pikachu
Response: {name: 'Pikachu', id: '25', type:['Electric'], weaknesses:['Ground'], height: '0.41 m', weight: '6.0 kg', next-evolution:[{num: '026', name: 'Raichu'}] }

/getPokemonNames - GET/HEAD

Query Params

(optional) Pokemon types to filter by

(optional) Pokemon weaknesses to filter by

Returns

array[string] of Pokemon names

Format: [{name: string}]

Example

Request: /getPokemonNames

Response: [{name: string}, {name: string} ...]

/searchAllPokemon - GET/HEAD

Query Params

(optional) Pokemon types to filter by

(optional) Pokemon weaknesses to filter by

Returns

Stringified array of JSON pokemon objects with simplified and reorded attributes

Format: [ {name: string, id: number, type:[string], weaknesses:[string], height: string, weight: string, next-evolution:[{num: string, name: string}] } ]

Examples

Request: /searchAllPokemon
Response: 400 bad request - must enter at least one type or weakness

Request: /searchAllPokemon?type=Fire
Response: [ {name: string, id: number, type:[string], weaknesses:[string], height: string, weight: string, next-evolution:[{num: string, name: string}] }, ...]

/addPokemon - POST

Body Params

Pokemon name - must be unique

Pokemon ID - must be unique

(optional) Pokemon type

(optional) Pokemon weakness

(optional) Pokemon height

(optional) Pokemon weight

Returns

Freshly created pokemon object with simplified and reorded attributes

Format: { name: string, id: number, type:[string], weaknesses:[string], height: string, weight: string, next-evolution:[{num: string, name: string}] }

Example

Request: /addPokemon
Body: {name: 'Raichu657', id: 1256 }
Response: 201 Created! Your new pokemon: { name: 'Raichu657', id: 1256, type:[''], weaknesses:[''], height: '', weight: '', next-evolution:[{num: '', name: ''}] }

/modifyPokemon - POST

Body Params

Pokemon name - used to find the existing pokemon

(optional) Pokemon new name

(optional) Pokemon ID

(optional) Pokemon type

(optional) Pokemon weakness

(optional) Pokemon height

(optional) Pokemon weight

At least one optional parameter must be entered (otherwise there will be no new data to add).
All optional parameters default to pre-existing values if left blank.

Returns

Freshly modified pokemon object with simplified and reorded attributes

Format: { name: string, id: number, type:[string], weaknesses:[string], height: string, weight: string, next-evolution:[{num: string, name: string}] }

Example

Request: /modifyPokemon
Body: {name: 'Pikachu', newName: 'Raichu657', id: 1256 }
Response: 200; Your modified pokemon: { name: Raichu657, id: 1256, ...OGPikachuData (see above for formatting) }
